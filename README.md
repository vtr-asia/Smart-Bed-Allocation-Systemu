# Smart-Bed-Allocation-Systemu
本應用為基於SMART on FHIR標準開發的營運管理工具，專注醫院床位調度與候床病人優先排序。系統透過FHIR launch流程，從電子病歷系統讀取Encounter（候床狀態）、Location（床位資源）等資料，運用規則驅動的智慧優先權演算法（權重：緊急度40%、ACLS等級25%、科別匹配20%、預期住院天10%、轉診/VIP各5%），自動計算病人優先分數、推薦最佳床位，並提供一鍵自動配床功能。包含即時床位使用率儀表板、候床清單排序、科別篩選與分數明細解釋。適合急診、護理站、床位中心使用，目標縮短候床時間、優先保障急重症病人、提升醫院營運效率。目前為純規則引擎、非AI類，已實作launch流程與mock資料演示，支援THAS沙盒測試。
